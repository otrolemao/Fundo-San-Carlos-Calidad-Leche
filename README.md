# 🐄 Sistema de Gestión de Calidad de Leche - Fundo San Carlos

## 📋 Descripción del Proyecto
Este repositorio contiene el código fuente y la documentación del Proyecto Integrador de la carrera de Ingeniería en Informática de INACAP.

El objetivo es desarrollar una **aplicación híbrida** (instalable en celular y computador) para digitalizar el historial de calidad de leche del Fundo San Carlos (COLUN), permitiendo registrar muestras de RCS y UFC, generar alertas tempranas y apoyar la toma de decisiones.

## 🛠️ Tecnologías a utilizar
*   **Frontend:** React Native / Flutter
*   **Backend:** Node.js + Express + TypeScript
*   **Base de Datos:** PostgreSQL (Supabase)
*   **Control de versiones:** Git + GitHub
